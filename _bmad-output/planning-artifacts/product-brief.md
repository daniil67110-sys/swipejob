# PRD — Application mobile “Tinder pour alternance/stage”
## Version 0.1 — Produit étudiant France 2026

---

# 1. Vision produit

Créer l’expérience de recherche de stage/alternance la plus fluide et addictive pour les étudiants français.

Le produit transforme :
- la recherche longue,
- stressante,
- répétitive,
- démoralisante

en une expérience :
- mobile-first,
- rapide,
- gamifiée,
- intelligente,
- personnalisée.

L’utilisateur ne “cherche” plus une alternance.
Il swipe des opportunités compatibles.

---

# 2. Problème

Aujourd’hui, trouver un stage ou une alternance en France est :
- lent,
- opaque,
- répétitif,
- administrativement lourd,
- émotionnellement épuisant.

Les étudiants doivent :
- refaire leur CV,
- remplir des formulaires,
- écrire des lettres similaires,
- chercher manuellement des offres,
- gérer les refus/silences.

Les plateformes existantes :
- sont pensées desktop,
- ont une UX vieillissante,
- demandent trop d’effort,
- créent beaucoup de friction.

---

# 3. Solution

Application mobile de matching stage/alternance basée sur :
- swipe,
- matching IA,
- candidature ultra simplifiée,
- profil unique,
- adaptation automatique du CV.

## Fonctionnement principal
- Swipe droite → candidature envoyée automatiquement
- Swipe gauche → passe
- Profil créé une seule fois
- Matching IA basé sur :
  - compétences,
  - localisation,
  - école,
  - expérience,
  - préférences,
  - chances de compatibilité.
